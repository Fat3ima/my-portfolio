# My Portfolio

A personal portfolio website built to showcase my projects, skills, courses, certificates, and writings.

🌐 **Live Website:**
https://fat3ima.github.io/my-portfolio/

## About

This portfolio is a front-end web application designed to present my work and professional profile in a clear and responsive interface.

The project is currently focused on the front-end and is continuously being developed as I expand my skills and add new projects and content.

## Built With

* React
* Vite
* Material UI (MUI)
* JavaScript (JSX)
* CSS
* React Router
* React i18next
* i18next HTTP Backend

## Features

* Responsive portfolio design
* English and Arabic language support
* Projects showcase
* Skills and technologies section
* Courses and certificates
* Writings / publications section
* CV access

* Custom fonts and UI components

## Getting Started

### Prerequisites

Make sure you have Node.js and npm installed.

### Installation

Clone the repository:

```bash
git clone https://github.com/Fat3ima/my-portfolio.git
```

Navigate to the project directory:

```bash
cd my-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available at the local URL provided by Vite.

## Build

To create a production build:

```bash
npm run build
```

The production files are generated in the `dist` directory.

## Deployment

The portfolio is deployed using GitHub Pages.

Deployment is handled automatically through GitHub Actions whenever changes are pushed to the `main` branch.

## Future Development

The project is actively evolving. Future plans include expanding the portfolio functionality and introducing a back-end system to manage portfolio content dynamically.
